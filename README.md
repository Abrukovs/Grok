# Лайнер

Ежедневный бриф идей по футболу, теннису, баскетболу и хоккею. Как выбираются матчи, что такое «спокойные» и где лежит журнал: [docs/КАК-РАБОТАЕТ.md](docs/КАК-РАБОТАЕТ.md).

```bash
npm install
npm run dev
```

Приложение слушает порт 8080. Журнал расчётов — `data/briefing-log.json`. Токен Telegram не хранится в git: скопируйте `data/telegram.example.json` в `data/telegram.json`.
