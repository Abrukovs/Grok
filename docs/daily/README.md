# Ежедневная линия

GitHub Actions собирает рейтинг сам, без чата.

- Расписание: каждый день в 12:00 по Риге зимой (10:00 UTC). Летом это будет 13:00 по Риге.
- Файл дня: `docs/daily/YYYY-MM-DD.md`, дата по Москве.
- Следить за запуском: вкладка Actions, workflow **Daily line**. Зелёная галочка значит, что прогон прошёл. Красный крест — лог ошибки.
- Запустить сразу: Actions → Daily line → Run workflow.

Скрипт `scripts/daily-line.mjs` берёт только ещё не начавшиеся матчи на 18 часов. Футбол, НХЛ, НБА и Евролига. Только победа фаворита при разрыве в таблице. Тоталов нет.
